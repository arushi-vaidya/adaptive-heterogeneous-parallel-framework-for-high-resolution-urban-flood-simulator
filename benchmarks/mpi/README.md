# MPI Benchmark Status

`availability.csv` is generated by `scripts/run_benchmarks.py` from the executable capability report. On this Apple M2, MPI was built with Homebrew Open MPI 5.0.11, compiled, and executed. The MPI CTest matrix passed 34/34 across 1/2/3/4/6 ranks; benchmark state and conservation gates passed for all measured rows. MPI per-rank memory is not measured.

The repeated benchmark study used 3 independent runs per configuration for the 512² matrix and for the flat-basin capacity study. The recorded output files are:

- `benchmarks/mpi/results-512.csv` — repeated 512² matrix for five scenarios at 1/2/4 ranks
- `benchmarks/mpi/results-capacity.csv` — repeated flat-basin 1024² and 2048² capacity checks at 1/2/4 ranks
- `benchmarks/mpi/summary.csv` — per-configuration summary with runtime, speedup, efficiency, and communication/computation values

```sh
python3 scripts/run_benchmarks.py --binary build-mpi/flood_sim \
  --backends mpi --scenarios flat-basin,slope,dam-break,rain-drain,wet-dry \
  --sizes 512x512 --processes 1,2,4 --repeats 3 --overwrite \
  --output benchmarks/mpi/results-512.csv

python3 scripts/run_benchmarks.py --binary build-mpi/flood_sim \
  --backends mpi --scenarios flat-basin --sizes 1024x1024,2048x2048 \
  --processes 1,2,4 --repeats 3 --overwrite \
  --output benchmarks/mpi/results-capacity.csv
```

The 512² repeated study produced mean speedups across the five scenarios of approximately 1.04x, 1.80x, and 2.45x at 1/2/4 ranks. The 1024² repeated flat-basin checks were 1.10x, 1.91x, and 2.70x at 1/2/4 ranks, and the 2048² flat-basin checks were 1.02x, 1.68x, and 2.36x. All measured runs preserved numerical tolerance and reported zero maximum depth error; the largest absolute conservation residual was approximately $5.82\times10^{-11}$ m³.

The six capacity rows are in `results-capacity.csv`; the 15 scenario rows are in `results-512.csv`. Metadata sidecars record configuration and host details. Timing columns describe the slowest rank and separate setup, computation, communication, synchronization, and other overhead. CSV runtimes are rounded to microseconds; the maximum absolute phase-sum residual is kept near zero. The plotter generates MPI runtime, speedup, efficiency, communication, numerical-error, and compute/communication/synchronization plots from these measured rows.

The runner discovers MPI launcher flags from CMake, compares depth and both momentum fields to serial, gates conservation, and records MPI diagnostics from executed runs. These are host-specific measurements for the Apple M2 + Homebrew Open MPI 5.0.11 configuration and should be interpreted as a small measured dataset rather than a general performance claim.
