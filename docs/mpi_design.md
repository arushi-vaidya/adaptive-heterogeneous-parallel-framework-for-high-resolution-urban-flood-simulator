# MPI Design

Status: compiled and experimentally validated with Homebrew Open MPI 5.0.11 on Apple M2/macOS. The MPI CTest matrix passed 34/34, covering one, two, three, four, and six ranks. Performance results are exploratory single runs, not repeated publication benchmarks.

The source uses `MPI_Dims_create` and a non-periodic `MPI_Cart_create` topology. A quotient/remainder block calculation gives each rank a contiguous rectangular interior and supports uneven grid divisions. If a process grid creates an empty block, all ranks reject it. Each local state has one ghost layer. The first-order axial face stencil needs only `bed`, `h`, `hu`, and `hv` on north/south/east/west edges; diagonal corner exchange is unnecessary.

The source posts `MPI_Irecv`/`MPI_Isend` for cardinal state halos and waits with `MPI_Waitall`. It then computes fluxes; no communication overlap is claimed. Because positivity limiting depends on donor outflow on all four sides, owned-cell limiter values are exchanged as an additional scalar halo before flux divergence. Physical wall/outflow ghosts are used only at global boundaries; partition interfaces use neighbor state. Rank 0 scatters the initial grid and gathers final owned cells for compatible CSV output.

Each timestep reduces local CFL wave-speed maxima with `MPI_Allreduce(MPI_MAX)`, then applies the existing CFL and rainfall-time clipping. Global volume/source budgets, min/max depth/velocity, and wet-cell counts are reduced. `MPI_Wtime()` records critical-rank setup, computation, halo communication, synchronization, other overhead, and total wall time. The phase intervals are disjoint; the total-minus-phase-sum residual is at most 3 microseconds in the recorded data, primarily because CSV total runtimes are rounded. Decomposition is static; adaptive load balancing/refinement is absent.

With MPI enabled, CMake compiles `src/mpi/MpiSolver.cpp` and registers serial-comparison tests for 1/2/3/4/6 ranks across five standard scenarios plus lake-at-rest. All 34 tests pass. Direct 100x101 rain-drain checks at three and four ranks exercised uneven decomposition and outflow boundaries; depth and both momentum files matched serial exactly. The 512² matrix (five scenarios, 1/2/4 ranks) and 1024²/2048² flat-basin capacity runs passed their state and conservation gates. Detailed measurements are in [benchmarks/mpi/README.md](../benchmarks/mpi/README.md).
